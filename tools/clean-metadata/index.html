    How it works

    1. Add your decks. Pick one or several .pptx files — the tool shows exactly which metadata it finds.
    2. Clean them. Author, last-saved-by, company, manager and custom properties are removed from the file.
    3. Download. Save the cleaned copy, or a ZIP for multiple decks.

    Why do this in the browser?

    Every PowerPoint file quietly carries a paper trail: the author's name, the company that owns the licence, the last person who saved it, and any custom properties the first template added. For job applications, client deliverables, anonymous submissions or published templates, that trail can leak more than you intended. This tool rewrites the document properties inside your browser — the file is never uploaded anywhere, so sensitive names never leave your machine.

    The tool shows you a report of every value it removed, so you can verify the result before you share the file. Slide content, design and structure are not touched in any way.

    FAQ

    Which properties get removed?

    Author (dc:creator), last-saved-by (cp:lastModifiedBy), company, manager and all custom document properties. Slide content, dates in the slide body and the deck's design are untouched.

    Will PowerPoint still open the file normally?

    Yes. The properties are simply emptied — the file keeps a valid structure and opens in PowerPoint, Google Slides and Keynote without any warning.

    Why not use PowerPoint's Document Inspector?

    You can — if you have PowerPoint. This tool exists for when you are on a shared or locked-down computer, want to batch-clean many files, or simply do not want to upload the deck to a web service.

    Can I clean a deck I received from someone else?

    Yes. The tool rewrites whatever metadata the file carries, regardless of who created it. Useful before re-publishing or forwarding decks you did not make.

    Does it work with .ppt or Google Slides files?

    Only .pptx is supported. In Google Slides use File → Download → Microsoft PowerPoint (.pptx) first; legacy .ppt files need a quick save-as .pptx in PowerPoint.
