    How it works

    1. Add your decks. Pick one or several .pptx files to inspect.
    2. Analyse. The tool reads the file structure locally and builds a fact sheet per deck.
    3. Read the numbers. Slides, words, images, charts, tables, media weight — no file is created or uploaded.

    Why do this in the browser?

    Word limits, slide limits and image-heavy decks come up constantly: conference CFPs ask for decks under 20 slides, style guides cap word counts per slide, and email systems reject files over 20 MB. This tool answers those questions without opening PowerPoint and without sending the file to a server — the deck is unpacked in your browser's memory and measured there. It is read-only: nothing is rewritten, so there is no output file to download.

    For multi-deck drops you get one fact sheet per file, which makes it easy to compare candidate decks before a pitch or to audit a folder full of presentations.

    FAQ

    Is anything uploaded or changed?

    No on both counts. The file is read in your browser's memory, measured, and forgotten. The original file is never modified and there is no download.

    How is the word count calculated?

    All visible text on the slides is counted — titles, body text, captions and labels. Speaker notes are counted separately so you can see both numbers.

    Why do my images show as zero?

    Only media embedded in the file counts. Linked images (files the deck references from your disk) are not part of the .pptx package and cannot be seen.

    Can it read .ppt or Google Slides files?

    Only .pptx. In Google Slides use File → Download → Microsoft PowerPoint (.pptx) first; legacy .ppt files need a quick save-as .pptx in PowerPoint.

    Does a big file always mean many slides?

    Not at all. The media weight line shows how much of the file is photos, video and audio — a 5-image deck can easily outweigh a 40-slide text deck. Pair it with our Compress PPT tool when the number is too high.
