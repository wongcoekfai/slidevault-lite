Five people sent you five decks. The all-hands is tomorrow, and the master file needs all of them, in order, without anyone's slides turning into a font disaster. Merging presentations is one of those tasks PowerPoint makes harder than it should be — mostly because the obvious method (copy, paste, pray) is the one that wrecks the design. Here are the four ways that actually work.

## Method 1: Copy and paste slides (the trap)

Open deck A, open deck B, copy B's slides in the thumbnail pane, paste into A. PowerPoint asks whether to **Use Destination Theme** or **Keep Source Formatting**.

The trap is that neither answer is complete. *Destination Theme* makes B's slides wear A's fonts and colors — usually badly, because B's layouts were designed around its own masters. *Keep Source Formatting* preserves the look but often drags in duplicate masters and layouts, bloating the file and leaving you with a template dropdown containing 40 near-identical layouts. For a two-deck merge you can clean up manually; for five decks, don't start down this road.

## Method 2: Reuse Slides (better, still manual)

In the destination deck: **Home → New Slide → Reuse Slides → Browse** to the other file, tick *Keep source formatting*, and click each slide you want.

This is the "correct" manual method — it imports properly through PowerPoint's own machinery. But it is still one deck at a time, one click per slide, and it silently reorders nothing: you are responsible for getting the sequence right. Fine for merging two decks of ten slides; an afternoon for a real all-hands.

## Method 3: Section-based assembly for recurring decks

If you merge decks *every week* — status reports from five teams, training modules from five trainers — the fix is organizational, not technical: give every contributor a **template with fixed section structure**, so their deck is section 1 and yours is section 2. Then any merge method becomes trivial because everyone's slides live in the same layout system.

Our [free PowerPoint templates](https://slidevaulte.com/#templates) work well as that shared skeleton: everyone starts from the same file, and the merged result looks like one person made it.

## Method 4: Automatic merging in the browser

For the general case — N decks, arbitrary designs, keep everything looking original — our free [Merge PPT tool](https://slidevaulte.com/tools/merge-ppt/) does it in one pass. Drop all the files in, drag to set the order, press merge. Each source deck keeps its own masters, layouts, fonts and backgrounds; nothing is re-themed, nothing is re-compressed. Everything runs in your browser, so unreleased financials or client decks never touch a server.

It handles the master-collision problem that makes manual merging messy: every file's design system travels with it, even when five decks use five completely different templates. Output is a single .pptx, typically ready in seconds.

## Choosing the right method

- **Same template, many authors** → any method works; copy-paste with destination theme is fine.
- **Different templates, one-off merge, under ~10 slides** → Reuse Slides with source formatting.
- **Different templates, big or recurring merge** → [automatic merging](https://slidevaulte.com/tools/merge-ppt/).
- **Need to pull one section out afterwards** → that is the reverse problem; [Split PPT](https://slidevaulte.com/tools/split-ppt/) breaks a merged deck back into parts.

## After merging: two quick checks

1. **File size grows additively.** Five decks of 40 MB each make a ~200 MB master, because every deck's media comes along. Run the result through [Compress PPT](https://slidevaulte.com/tools/compress-ppt/) — image-heavy decks routinely shrink 40–90% with no visible change.
2. **Flip through once at real speed.** Merges break in the transitions between decks — inconsistent margins, mismatched footer dates, a section title that assumes context the merged file no longer has. Thirty seconds of flipping catches them all.

The merged all-hands deck is a compilation, but it should not look like one. Start contributors on a common template, merge automatically, compress before you send — and the file reads like a single, deliberate presentation.
